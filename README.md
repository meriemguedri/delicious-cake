# Delicious Cake

A Django-based e-commerce web application for a bakery, developed independently as a personal academic project.

## Features

- Product display
- Shopping cart and order functionality
- User authentication and user management
- SQLite database integration
- Input validation and error handling

## Technologies

- Python
- Django
- HTML and CSS
- SQLite
- PythonAnywhere

## Run Locally

1. Clone the repository.
2. Create and activate a Python virtual environment.
3. Install the dependencies listed in `requirements.txt`.
4. Configure the required environment variables, if applicable.
5. Apply database migrations.
6. Start the Django development server.

Example commands:

```bash
python -m venv .venv
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

The exact setup may vary depending on the project's configuration.

## Project Context

Independently developed to practice web application development, database integration, user management, and deployment.
